# My Finance V9

Responsive personal finance tracker for Windows and Android.

## Setup
1. Open config.js.
2. Replace PASTE_YOUR_SUPABASE_PUBLISHABLE_KEY_HERE with your Supabase sb_publishable_... key.
3. Upload the V9 files to GitHub Pages.
4. Do not use an sb_secret_... key.

## V9 UI
- Mobile bottom navigation
- Desktop sidebar
- Dashboard with income/bills/paid/pending
- Due-soon list
- Monthly spending chart
- Bills, payments, income
- Credit card cards with utilization
- EMI progress
- Calendar
- Reports
- Reminders
- Persistent Supabase Auth session
- Automatic token refresh
