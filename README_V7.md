# My Personal Finance Tracker V7

1. Extract this folder.
2. Run `python -m http.server 8000` from this folder.
3. Open http://localhost:8000
4. Click Setup.
5. Enter your Supabase Project URL and the `sb_publishable_...` Publishable key.
6. Login using your Supabase Auth email/password.

Never use or expose an `sb_secret_...` or service-role key. Do not commit real financial data or secrets to GitHub.
