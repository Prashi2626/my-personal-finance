# My Personal Finance Tracker V10

V10 adds **Download Excel** to Reports.

The Excel workbook contains:
- Summary
- Bills
- Payments
- Income
- Credit Cards
- EMIs
- Reminders
- Categories
- Bill Status

**Important:** keep your existing working `config.js` unchanged. Do not overwrite it with an older copy.

The export uses SheetJS from jsDelivr to generate a real `.xlsx` file in the browser.
